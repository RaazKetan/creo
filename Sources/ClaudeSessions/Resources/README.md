Service marks used only to identify the corresponding services in the dock.

- `chatgpt.svg`: OpenAI mark from Simple Icons v15.0.0 (`icons/openai.svg`), rendered white for the dark dock.
- `claude.svg` and `perplexity.svg`: Claude and Perplexity marks from Simple Icons (`cdn.simpleicons.org`), rendered white.
- PNG files are 192px rasterizations of those SVGs for AppKit.
